INTERPRETADOR / V2.0

Uma linguagem pequena. Um fluxo completo.

vaga A1 comum cria uma vaga. entrada "ABC1234" registra presença. estacionar "ABC1234" em A1 ocupa a vaga. Para sair, use liberar A1 e depois saida "ABC1234".

definir cliente: veiculo = "ABC1234" cria um nome tipado. bloco { ... } delimita nomes locais. Os exemplos mostram tipos, escopos e erros. Cada execução começa com estado vazio; o editor aceita somente a DSL, sem comandos Python.

Atalho: Ctrl + Enter para executar. Os identificadores de veículo têm sete letras maiúsculas ou dígitos; não são uma validação de placas brasileiras.
